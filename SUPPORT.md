# Support

Semantic Rails is an Apache-2.0-licensed open-source project.

Use GitHub issues for:

- Reproducible bugs.
- Documentation gaps.
- Feature requests tied to the supported runtime.
- Questions about authoring or running packages.

Before opening an issue, please include the command you ran, the package you used, and the relevant
error output or response body. For security concerns, use [SECURITY.md](SECURITY.md) instead of a
public issue.

Community support is best-effort. The repository does not promise hosted service support, private
SLAs, tenant operations, or managed warehouse administration.
