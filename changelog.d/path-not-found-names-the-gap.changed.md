- `PATH_NOT_FOUND` names what keeps a call's start from its target when no relationship chain
  joins them: the relationship that allows only the other walk, the key one side already holds,
  the entity that holds both keys, or the identifier both share that is a key of neither
  (`details.missing_link`, also in the message), and the nearest entity the start reaches. It
  ranks the reachable dimensions and the measures that come closest to what was asked, and each
  hint says whether it is for the caller or the package author. A misspelled entity gets its
  closest ids instead. See [MCP interface](docs/MCP_INTERFACE.md).
