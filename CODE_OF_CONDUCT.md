# Code Of Conduct

## Expectations

Participants are expected to keep discussion technical, respectful, and focused on improving the
project. Good-faith disagreement is welcome; harassment, insults, personal attacks, and disruptive
behavior are not.

## Scope

This code of conduct applies to project issues, pull requests, discussions, and other community
spaces associated with this repository.

## Enforcement

Maintainers may edit, hide, lock, or remove comments and issues that violate these expectations.
Repeated or severe violations may result in blocked participation in the repository.

## Reporting

Report conduct concerns to the maintainer,
[@wtremml18](https://github.com/wtremml18), by opening an issue on
[github.com/semantic-rails/semantic-rails/issues](https://github.com/semantic-rails/semantic-rails/issues)
that mentions `@wtremml18` — or, when the report should not be public, by contacting
@wtremml18 directly through their GitHub profile. Include links and context.
Security vulnerabilities should be reported through [SECURITY.md](SECURITY.md) instead.
